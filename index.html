日本語校正ツールへようこそ

このアプリでできること

  • 誤字・脱字・表記ゆれの検出
  • 冗長表現や読みにくい長文の指摘
  • 「ですます／である」混在チェック
  • 独自辞書のインポート／エクスポート
  • オフラインでも動作（一度開けばネット不要）

iPhoneにインストール（Safari）

  1. Safariでこのページを開きます。
  2. 下部または上部の「共有」ボタン ⬆️ をタップ。
  3. 「ホーム画面に追加」を選択。
  4. 「追加」をタップしてホーム画面から起動。

Androidにインストール（Chrome）

  1. Chromeでこのページを開きます。
  2. 右上のメニュー ⋮ を開く。
  3. 「アプリをインストール」または「ホーム画面に追加」を選択。
  4. 確認ダイアログで「インストール」をタップ。

使い方

  1. テキスト入力欄に校正したい文章を貼り付けます（最大30,000文字）。
  2. 「校正する」ボタンをタップ。
  3. 右側に指摘が一覧表示されます。タップで該当箇所へジャンプ。
  4. 不要な指摘は「無視」で個別に消せます。
  5. 辞書管理から、業務や用途に合わせた辞書を有効化できます。

ヒント: Ctrl/⌘ + Enter で校正、Ctrl/⌘ + S で保存できます。
